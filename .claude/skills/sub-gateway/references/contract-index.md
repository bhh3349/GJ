## 三条铁律（写代码前先背）

1. **两套错误体不许混**：`/v1/*` 是 OpenAI 形状 `{error:{message,type,code}}`；`/api/*` 是 `{code,message,details?}`。
2. **类型口径**：金额 = 分 (int)、token = int、时间 = ISO8601 **UTC** 字符串。别用 float 存钱、别用本地时间。
3. **跨边界改动先改契约再改代码**；契约有疑问问管家，不要单方面改字段。
